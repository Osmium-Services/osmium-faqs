title: Add a list of FAQs

A FAQ list is a named set of questions and answers. Your site's design decides where each list appears.

## Create a list

1. Open **FAQs** in the Content group of the admin menu and choose to add a list.
2. Give it a **List name**. The **Slug** is the short, lower-case name your site uses to find the list, so keep it simple.
3. Press **Add question**. Type the question and its answer.
4. Repeat for each question.
5. Press **Save**.

## Change the order

Each question has up and down arrows. Use them to move a question, then Save.

## Hide a question without deleting it

Each question has a **Shown on the site** switch. Turn it off to keep the question in the list but stop it appearing on the site.

## Remove a question

Use the bin button on the question, then Save. Nothing is removed until you save.
